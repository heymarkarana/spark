How it works

  
    
    
  • The command downloads spark.sh of the pinned release (unpublished) and checks it against the SHA-256 shown on this page, which was stamped in when the page was published. Only then does it run bash spark.sh with your values as flags. A failed download, or a corrupted or swapped file, stops it before spark runs.
    • 
    
  • Every value is a plain command-line flag. The script fetched is always the same tagged file; nothing is customised for you, and there is no redirect.
    • 
    
  • The expected SHA-256 of spark.sh: (unpublished). The same hash is printed in the release notes, if you want to compare it independently.
    • 
  

  
What it does not do

  
    
    
  • This page comes from the same repository as spark.sh, so the hash check refuses a corrupted or swapped download but does not protect against a compromised repository.
    • 
    
  • This page never sends your input anywhere: no network requests, no cookies, no storage. The shareable link keeps your values after # because URL fragments are not sent to servers.
    • 
    
  • A branch install is not verified at all. It is for development and testing only.
